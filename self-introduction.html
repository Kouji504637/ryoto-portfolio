PROFILE　/　RYOTO WATANABE

自己紹介

身近なものをよく見て、面白さを見つけ、デザインで伝えることを大切にしています。

名前
渡邉 諒人
興味
デザイン / 車 / 音楽 / ドライブ

デザインについて

伝えたいことを整理し、見る人が迷わず受け取れる形にすることを意識しています。地域や日常で見つけた題材を観察し、グラフィックやWebの制作に取り組んでいます。

01　/　PROFILE

好きなこと

デザインに触れること、車で出かけること、音楽を聴くこと。気になったものを見つけると、形や色、使われ方をじっくり眺めます。

02　/　APPROACH

制作で意識していること

まず題材や目的を考え、伝える内容に合わせて情報や見せ方を組み立てます。見た目と使いやすさの両方を考えた制作を目指しています。

03　/　TOOLS

取り組んでいる分野

グラフィックデザイン、Webデザイン、情報の構成。課題制作を重ねながら、表現の幅を広げています。
